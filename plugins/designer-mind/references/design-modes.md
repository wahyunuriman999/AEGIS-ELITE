# Design Modes

Load this reference when the task involves a specific design medium (web, mobile, dashboard, e-commerce, brand, poster, social media, AI product).

---

## Web Design Mode

Think as: Art Director + UX Designer + UI Designer + Creative Developer.

Consider: navigation, information architecture, hero, trust signals, content hierarchy, CTA, conversion, responsiveness, accessibility, performance, interaction.

**Hero must answer:** What is this? Why should I care? What should I do next?

---

## Mobile App Design Mode

Usability first, then visual personality. Do not shrink desktop UI — redesign for mobile behavior.

Consider: thumb zones, bottom navigation, gesture interaction, pull-to-refresh, haptic feedback, offline states, reduced animation, battery impact, touch targets (44px min).

---

## Dashboard Design Mode

Prioritize: clarity, scannability, data density, hierarchy, actionability.

Data must remain legible. Use: sparklines, heatmaps, KPI cards, comparison charts, status indicators. Avoid: excessive 3D charts, decorative backgrounds behind data, low-contrast data labels.

---

## E-Commerce Design Mode

Prioritize: product, trust, discovery, comparison, conversion.

The product is always the hero. Consider: high-quality imagery, zoom, size guides, reviews, urgency without manipulation, clear pricing, shipping info, return policy visibility.

---

## Product Showcase Mode

Think beyond static images. Possible: 3D rotation, zoom, material switching, color configuration, hotspots, exploded view, comparison slider, scroll reveal, video integration.

---

## Branding Mode

Branding begins with personality, not color. A brand is a system.

Define: voice, values, visual language, typography, color meaning, imagery style, interaction signature, consistency rules.

---

## Graphic Design Mode (Posters, Ads, Social, Presentations)

Execution order: Concept → Composition → Typography → Image → Light → Color → Detail.

Poster: one idea, maximum impact. Social: platform-native aspect ratios, scroll-stopping first frame. Presentation: one idea per slide, progressive reveal.

---

## AI Product Design Mode

Reject the standard chat interface when the task benefits from something better.

| AI Output | Better Interface |
|---|---|
| Code | Syntax-highlighted editor |
| Image | Gallery / masonry / comparison |
| Data | Interactive visualization |
| Document | Structured viewer |
| Plan | Timeline / roadmap |
| Analysis | Insight dashboard |
| Table | Interactive data table |

For AI agents: show task progress, tool activity, generated artifacts, approval actions, system states. Users need to understand: what the AI is doing, what it produced, what needs attention.

---

## Image Art Direction Mode

Build image prompts systematically:

```
[MEDIUM] + [SUBJECT] + [POSE/ACTION] + [COMPOSITION] + [ENVIRONMENT] +
[CAMERA] + [LENS] + [LIGHTING] + [COLOR] + [MATERIAL] + [ATMOSPHERE] +
[ART DIRECTION] + [QUALITY] + [ASPECT RATIO] + [NEGATIVE CONSTRAINTS]
```

Preferred: cinematic, editorial, controlled lighting, strong composition, intentional depth. Avoid meaningless adjective stacking — every descriptor must control something.

### Aspect Ratios

| Format | Use |
|---|---|
| 9:16 | Mobile / stories / reels |
| 16:9 | Desktop / presentation / cinematic |
| 1:1 | Square social |
| 4:5 | Social portrait |
| 3:2 | Photography / editorial |

---

## Campaign Consistency

When producing a series: consistency is law. Define a visual anchor (color, typography, composition pattern, lighting). Every output must feel like it belongs to the same campaign.
