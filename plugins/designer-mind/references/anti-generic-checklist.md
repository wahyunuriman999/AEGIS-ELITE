# Anti-Generic & Human Craft Checklist

Load this reference before finalizing any design to ensure the output transcends generic AI patterns.

---

## Core Principle

Do not optimize for "beautiful." Optimize for: **INTENTIONAL · SPECIFIC · HUMAN · MEMORABLE · CONTEXTUAL · BELIEVABLE · CRAFTED.**

---

## AI Pattern Detection — Eliminate Before Shipping

- [ ] Generic gradients (no purpose)
- [ ] Excessive glassmorphism
- [ ] Excessive rounded cards
- [ ] Repetitive card grids
- [ ] Meaningless floating objects
- [ ] Random blobs / glow / neon
- [ ] Excessive symmetry
- [ ] Excessive centered layouts
- [ ] Generic dashboard layouts
- [ ] Generic hero sections
- [ ] Predictable section patterns (Navbar → Hero → 3 Cards → Features → Pricing → CTA)
- [ ] Unnecessary 3D objects
- [ ] Excessive shadows / blur
- [ ] Decorative particles
- [ ] Generic stock imagery
- [ ] Repetitive icon usage
- [ ] Meaningless micro-interactions
- [ ] Excessive animations
- [ ] Generic AI copywriting ("Experience the future", "Unlock your potential", "Where innovation meets possibility")
- [ ] Lorem ipsum / John Doe / placeholder content when realistic content is possible

---

## Visual Specificity Test

Ask: **"What makes this design impossible to swap with another brand without looking wrong?"**

If the answer is "nothing": the design is too generic. Rework it.

---

## Human Art Direction Test

1. Could this have been designed by a real art director?
2. Would a designer have made this exact composition?
3. Does the imagery feel selected rather than generated?
4. Does the typography feel deliberately art-directed?
5. Does the spacing feel intentional?
6. Does the visual metaphor relate to the product?
7. Does the interaction communicate something?
8. Does the design contain a point of view?

---

## Hierarchy Test

Do not make every element equally polished, visible, animated, or important.

- Some elements should **dominate**
- Some should **recede**
- Some should **disappear**
- Some should **surprise**

Perfection without hierarchy feels artificial.

---

## Design Tension

When appropriate, introduce controlled tension through: scale, asymmetry, contrast, cropping, spacing, typography, light, material, motion.

Use tension for memorability. Never introduce tension merely to appear experimental.

---

## Controlled Irregularity

Allow when appropriate: asymmetric composition, unexpected spacing, unconventional cropping, editorial tension, unusual scale, deliberate overlap, non-uniform rhythm.

Every imperfection must be intentional. Do not introduce random imperfections.

---

## Content Realism

Create content appropriate to: industry, audience, product, location, brand, use case.

Avoid generic placeholders unless explicitly requested.

---

## Visual Restraint

AI tends to add. Senior designers remove.

Before finalizing: remove one thing. If the design becomes stronger, keep it removed.

---

## Final Anti-AI Test (Run Before Every Delivery)

1. Does this look like a template?
2. Does this look like generic AI output?
3. Is every decorative element necessary?
4. Is the visual language specific to this project?
5. Is there a clear human point of view?
6. Is the composition memorable?
7. Does anything feel algorithmically repeated?
8. Does the copy sound like a real person?
9. Does the interaction have a reason?
10. Would removing 20% improve it?

If YES to any major concern: **revise before finalizing.**

---

## Human-First Command

**Do not try to look like a human designer. Think like one.**

1. Understand the context
2. Form an opinion
3. Make a design decision
4. Justify it
5. Execute it
6. Critique it
7. Refine it

The goal is not "less AI-looking." The goal is **"more intentional."**
